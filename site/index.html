Let a monkey loose on your test environment

A command line tool that drives a real browser with Playwright, clicks, types and submits its way through your site with seeded randomness and reports what breaks: uncaught errors, failing requests, broken pages. Every finding comes with the steps to reproduce it.

Status: milestone M4. The seeded random monkey with oracles, reports and replay; Claude on Microsoft Foundry or any OpenAI-compatible endpoint for stuck situations; cookie banners, native dialogs, iframes, popups, uploads and downloads handled; parallel runs per role and seed, and a CI example. See the roadmap.

What PlayMonkey does for you

Seeded random monkey

Clicks links and buttons, fills forms with valid and nasty values and explores unvisited states. The same seed gives the same run.

An LLM only when stuck

Cookie banners, dialogs, forms that need valid data or a login wall: a model takes over for a few steps, then the monkey continues.

Findings, not noise

Oracles watch for uncaught exceptions, console errors, HTTP 4xx and 5xx, crashes, hangs, error pages and layout overflow, deduplicated.

Reproducible by design

Every action is logged with a durable locator. monkey replay runs the log again without an LLM; traces and videos show what happened.

Built for test environments

PlayMonkey clicks, deletes and submits anything it finds. Point it only at environments you can reset.

  • No guardrails, on purpose. There is no read-only mode and no confirmation; that is how it finds the bugs.
  • Runs always end. maxSteps and maxMinutes stop every run.
  • It stays on your site. With stayOnDomain (on by default) links to other origins are not followed.
  • Secrets come from the environment. ${VAR} placeholders are resolved at start and masked as *** in all output.
  • Each role is isolated. Every login runs in its own browser context; cookies never leak between roles.

Get started

Requires Node.js 22 and a Playwright browser. Describe the site in a JSON config; secrets stay in environment variables.

{
  "baseUrl": "https://test.example.org",
  "auth": [
    {
      "name": "admin",
      "loginUrl": "/login",
      "fields": { "username": "${ADMIN_USER}", "password": "${ADMIN_PASS}" },
      "submit": "button[type=submit]"
    }
  ]
}
  1. Install. Clone the repository, run npm ci, npx playwright install chromium and npm run build.
  2. Configure. Write a config like the one above and export the variables it references.
  3. Run. npx monkey run config.json logs in, explores every role and lists the findings, each with a screenshot and the steps that led to it.

The getting started tutorial walks you through it against the bundled fixture site; the configuration reference lists every key.
